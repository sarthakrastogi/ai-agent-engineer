WHAT EACH FILE DOES
───────────────────

CODE FILES
──────────

hr_agent.py (~130 lines)
  - Main agent implementation
  - Functions:
    • load_policies()                - Reads all .md files from policies/
    • format_policies_for_context()  - Concatenates into one string
    • create_system_prompt()         - Embeds policies in system prompt
    • answer_question()              - Single LLM call with caching
    • interactive_mode()             - REPL for multi-turn conversation
    • main()                         - Entry point
  - Uses: Anthropic SDK, pathlib, sys
  - No external tools or dependencies beyond anthropic package

test_agent.py (~40 lines)
  - Test suite with 7 typical employee questions
  - Runs questions through agent in sequence
  - Maintains conversation history across questions
  - Output: Q&A pairs for manual verification
  - No automated assertions (would need eval framework)

llm.py (~20 lines, pre-existing)
  - Thin wrapper over Anthropic Messages API
  - Functions:
    • complete()  - Calls Claude with system/messages/tools
    • text_of()   - Extracts text from response
  - Used by: Tests and other CLI tools
  - Can be ignored for agent operation (hr_agent.py is standalone)

requirements.txt
  - Single dependency: anthropic>=0.30.0
  - Install with: pip install -r requirements.txt


POLICY FILES (Auto-loaded)
──────────────────────────

Leave policy (v3, effective 1 April 2026)
  - Annual leave: 20 days/year (pro-rated for part-time)
  - Carry-over: Max 5 days to next year (rest lapse 31 March)
  - Sick leave: 10 days/year, cert required for 3+ consecutive days
  - Parental leave: 26 weeks paid (primary carer, after 6 months service)

Expenses policy (v2)
  - Claims: Submit in Expenso app within 60 days, need itemised receipt
  - Meals while travelling: Max NZD 80/day
  - Client entertainment: Needs manager approval (alcohol not covered otherwise)
  - Large claims: >NZD 500 need director approval

Remote-work policy
  - Up to 3 days/week with manager agreement
  - Overseas >2 weeks: Needs HR + tax approval
  - Home office allowance: NZD 400 every 3 years

Travel policy
  - Book via TravelDesk
  - Economy: <6 hours; Premium economy: 6+ hours
  - Approvals: Manager (domestic), Director (international)

Equipment policy
  - Laptop refresh: Every 3 years per employee
  - Lost/stolen: Report to IT within 24 hours
  - Personal devices: Email only via Intune app

STARTUP GUIDE
─────────────

1. One-time setup:
   cd hr-policy-agent
   pip install -r requirements.txt

2. Per-session setup:
   export ANTHROPIC_API_KEY=sk-ant-...

3. Run agent:
   python hr_agent.py

4. Or run test:
   python test_agent.py


KEY METRICS
───────────

Cost per query:
  • First query (uncached):     ~$0.0015
  • Subsequent queries (cached): ~$0.00015
  • Monthly (100 q/day):         ~$2.25

Latency per query:
  • First query:     1-2 seconds (network + inference)
  • Cached query:    <500ms

Context sizes:
  • All policies:               ~3 KB
  • System prompt:              ~3.5 KB
  • Max conversation history:   ~100 turns = ~10 KB
  • Total per session:          ~13.5 KB


CUSTOMIZATION QUICK TIPS
─────────────────────────

Add a new policy:
  1. Create policies/myPolicy.md
  2. Write markdown with clear sections
  3. Restart agent (it auto-discovers)

Change system prompt tone:
  1. Edit create_system_prompt() function in hr_agent.py
  2. Keep policies in context
  3. Test with a few questions

Switch to a different model:
  1. Change line: model="claude-opus-5-5"
  2. Options: claude-sonnet-5-5, claude-haiku-5-5
  3. Test and compare results

Add caching to responses:
  1. Already implemented (system prompt cached)
  2. Cache TTL: 5 minutes
  3. View stats in console output


TROUBLESHOOTING BY SYMPTOM
──────────────────────────

"No module named anthropic"
  → pip install -r requirements.txt

"AuthenticationError: Incorrect API key"
  → export ANTHROPIC_API_KEY=sk-ant-...

"No policy files found"
  → Check: pwd, ls policies/

"Question takes 10+ seconds"
  → Check: Internet connection, API status

"Answer doesn't cite sources"
  → Bug (report it) or out-of-context question

"Agent hallucinates policies"
  → Bug (report it) - agent should stick to loaded policies
