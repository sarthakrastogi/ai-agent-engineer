🚀 QUICK START

1. Install dependencies:
   $ pip install -r requirements.txt

2. Set API key:
   $ export ANTHROPIC_API_KEY="your-key-here"

3. Run the agent:
   $ python3 hr_agent.py

4. Ask a question:
   You: How many vacation days do I get?
   Assistant: Based on the Leave policy, full-time employees accrue 20 days...

🔧 CUSTOMIZATION

Adding a new policy:
  1. Create policies/new_policy.md
  2. Restart agent
  3. Done! No code changes needed

Changing response style:
  - Edit build_system_prompt() in any agent file
  - Adjust tone, format, examples

Switching models:
  - Change model parameter in API calls
  - claude-opus-5-5: Best accuracy
  - claude-sonnet-5-5: Balanced
  - claude-haiku-5-5: Fastest/cheapest
